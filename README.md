# 🎓 StudyMates – Student Task Manager
**Your Study, Your Progress.**

## 📌 About the Project
StudyMates is a student task management website designed to help students organise their academic tasks and study schedules. This website allows students to manage assignments, track task progress and plan their study time more effectively.

The main purpose of StudyMates is to help students stay organised, manage their time and complete their academic tasks on time.

## ✨ Features

- **Login Page** – Allows users to log in to the website.
- **Dashboard** – Displays an overview of tasks, completed tasks, pending tasks and task progress.
- **My Tasks** – Allows users to add, edit, delete, search and filter academic tasks.
- **Completed Tasks** – Displays completed assignments and their completion dates.
- **Study Planner** – Allows users to create and manage personal study schedules.
- **Dark Mode** – Provides a dark mode option for a comfortable viewing experience.
- **Local Storage** – Saves task information and study plans in the browser.

## 💾 Data Storage
StudyMates uses browser Local Storage to save task information and study plans. The data remains available in the same browser unless the browser storage is cleared.
