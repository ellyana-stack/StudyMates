# StudyMates
StudyMate is a student task management website designed to help students organise their assignments and study schedules. It allows users to manage tasks, track completed assignments, monitor their progress through charts, and plan their study activities.
The main purpose of StudyMates is to help students stay organised, manage their time and complete their academic tasks on time.

 Features:
1.Login Page – Allows users to log in to the website.
2.Dashboard – Displays an overview of tasks, completed tasks, pending tasks and task progress.
3.My Tasks – Allows users to add, edit, delete, search and filter academic tasks.
4.Completed Tasks – Displays completed assignments and their completion dates.
5.Study Planner – Allows users to create and manage personal study schedules.
6.Dark Mode – Provides a dark mode option for a comfortable viewing experience.
7.Local Storage – Saves task information and study plans in the browser.

Technologies Used:

2.CSS3
3.JavaScript

Data Storage:
